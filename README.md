**KØRE Terminal** is a simplified, hacker-themed command interface for Kali Linux that lets you create custom shortcuts for long commands, with automatic tool installation and full Linux command support.

---

## 🚀 Key Features
*   **Custom Command Shortcuts** — Create your own short aliases with ID system
*   **Add / Edit / Delete** commands directly inside the terminal
*   **Auto Tool Installation** — Automatically installs missing tools like nmap, msfconsole, sqlmap, etc.
*   **Command History** — Up/Down arrow support (works great in Termux)
*   **Native Linux Commands** — `ls`, `cd`, `pwd`, `mkdir` and all others work normally
*   **Hacker Green Theme** with clean KØRE branding
*   **Starts in Home Directory** (`\~`)
*   **Persistent Storage** of all your custom commands
